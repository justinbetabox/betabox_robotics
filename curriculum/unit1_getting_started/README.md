# Unit 1 — Getting Started

In this unit, students learn how to control a Betabox robot using Python and Jupyter notebooks.

The lessons begin with simple, immediate interactions and gradually introduce movement, sensors, audio, and vision.

## Lessons

1. Meet Your Robot
2. Driving
3. Lights
4. Audio
5. Sensors
6. Camera
7. Color Detection
8. Face Detection
9. First Robot Program

## Goals

By the end of this unit, students should be able to:

- Run code in a Jupyter notebook
- Create and close a Betabox robot
- Control basic robot movement
- Use audio and visual feedback
- Read sensor values
- Capture images
- Use built-in vision detection
- Combine multiple robot capabilities in a small program

## Safety

Always place the robot on the floor before running movement code.

Keep hands, cables, and other objects away from the wheels.

Stop the robot immediately if it moves unexpectedly.
