
# Unit 1 — Python Foundations

## Overview

In this unit, students learn the fundamentals of Python programming using JupyterLab.

Students begin by learning how to navigate and execute code in Jupyter notebooks. They then explore variables, comparisons, decisions, functions, loops, imports, and collections.

The lessons use approachable examples and robotics-related scenarios to prepare students for programming their Betabox car.

## Lessons

1. **Welcome to Jupyter** — Learn to run cells, manage the kernel, and navigate notebooks.
2. **Your First Python Code** — Write instructions, perform calculations, work with text, and recognize errors.
3. **Variables and Values** — Store information, work with data types, and update values.
4. **Comparisons and Decisions** — Compare values and control program behavior using conditions.
5. **Functions, Arguments, and Return Values** — Use built-in functions and create reusable functions.
6. **Loops and Repetition** — Repeat instructions using `for` and `while` loops.
7. **Imports and Libraries** — Import Python modules and discover the Betabox Robotics library.
8. **Lists and Collections** — Organize data using lists, tuples, and dictionaries.

## Learning Goals

By the end of this unit, students should be able to:

- Navigate JupyterLab and execute Python code.
- Understand variables and common Python data types.
- Write conditional statements.
- Define and call functions.
- Use loops to repeat instructions.
- Import modules and libraries.
- Store and manipulate collections of values.
- Debug common Python errors.
- Combine these concepts into small programs.

## Getting Started

Open the lessons in numerical order using JupyterLab.

Select the **Robot Car** kernel when prompted.

Each lesson includes explanations, examples, opportunities to practice, and a final challenge.

## Next Unit

After completing Python Foundations, students will apply these programming skills to controlling and interacting with their Betabox car.
